# House Price Prediction System

## Project Overview
This project predicts house prices based on features such as area and number of bedrooms using Machine Learning.

## Objective
To estimate the selling price of a house using historical housing data.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit (Optional)

## Machine Learning Algorithm
- Linear Regression

## Features
- Predict house prices instantly
- User-friendly input system
- Easy to understand implementation
- Suitable for beginners

## Input Parameters
- Area (Square Feet)
- Number of Bedrooms

## Output
- Predicted House Price

## Project Workflow
1. Collect housing data
2. Train Linear Regression model
3. Accept user inputs
4. Generate price prediction

## Future Improvements
- Add more housing features
- Use larger datasets
- Deploy on cloud platforms

## Conclusion
The project demonstrates how Machine Learning can be used to estimate property prices accurately.
